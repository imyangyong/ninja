# 组件复用优先

改动涉及 UI 实现时，优先使用项目已有组件，即使与设计稿样式有差异。

复用优先级：项目封装的共享组件 > 项目已引入组件库的组件 > 新写组件。

- 先检查项目的共享组件目录和已引入的组件库，确认可复用的组件。
- 设计稿与已有组件存在样式差异（颜色、间距、圆角、字号等）时，直接复用已有组件，不额外还原设计稿样式。
- 存在显著差异时停下向用户报告差异并询问，由用户裁决。显著差异包括：组件类型改变（如弹窗改为抽屉）、交互流程不同、设计稿要求已有组件不支持的能力。
- 已有组件确实无法满足需求时，优先在已有组件上扩展或组合，而非平级新写。

## 完成标准

- 改动范围内每个新增 UI 元素均已使用项目已有组件，或有用户确认的例外。
- 每个显著差异均已向用户报告并获得裁决。
