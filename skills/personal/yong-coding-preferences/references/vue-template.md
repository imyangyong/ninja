# Vue Template

在页面级 Vue 组件的 `<template>` 中，按页面布局模块添加含义注释。

- 在每个主要模块的根节点前添加注释，例如页面头部、搜索条件、数据列表、详情区、侧栏、分页区。
- 注释表达模块的业务或布局含义，并沿用文件已有的注释语言和格式。
- 注释保持在模块粒度；一个注释覆盖其完整模块。
- 新增或实质修改页面布局时，同步补齐改动范围内的模块注释。

```vue
<template>
  <main>
    <!-- 搜索条件 -->
    <section>
      <!-- ... -->
    </section>

    <!-- 用户列表 -->
    <section>
      <!-- ... -->
    </section>
  </main>
</template>
```

## 完成标准

每个新增或实质修改的 Vue 页面布局模块都有清晰的模块含义注释。
